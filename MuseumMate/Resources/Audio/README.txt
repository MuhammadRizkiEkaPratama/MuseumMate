HOW TO ADD TO XCODE:
1. Put your .mp3 files in this folder (Resources/Audio/)
2. In Xcode: right-click the Audio group → "Add Files to MuseumMate"
3. Select all .mp3 files → check "Copy items if needed" + "Add to target: MuseumMate"
4. Build & run. The player discovers them automatically.
